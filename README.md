## 🚀 Run Locally

No build step or backend is required.

```bash
git clone https://github.com/Harsh0675/Portfolio.git
cd Portfolio
```

Open `index.html` in a modern browser, or serve the folder with any static HTTP server.

## 🎯 Portfolio Purpose

The portfolio is designed to present software development work in a single, easy-to-navigate experience. Project cards connect visitors to individual demos while the skills section communicates the technologies and engineering areas represented across the work.

## 🔒 Notes

This is a client-side static website. External resources such as Google Fonts and Font Awesome are loaded from their respective CDNs.
